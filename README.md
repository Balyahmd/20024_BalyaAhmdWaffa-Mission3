# 🎥 Videobelajar - MVP Landing Page

Landing Page **Videobelajar** merupakan proyek MVP (Minimum Viable Product) yang dibuat menggunakan **HTML5** dan **CSS3**. Website ini terdiri dari tiga halaman utama yaitu **Login**, **Register**, dan **Beranda** dengan desain yang responsif sehingga dapat diakses melalui desktop maupun perangkat mobile.

---

## 📌 Tujuan Proyek

Membangun landing page sederhana untuk aplikasi **Videobelajar** sesuai dengan ketentuan yang diberikan, meliputi:

- Login Page
- Register Page
- Beranda
- Responsive Design (Desktop & Mobile)

---

# 📋 Pemenuhan Soal

## 1. Membuat MVP Landing Page

✅ Landing page berhasil dibuat untuk aplikasi **Videobelajar**.

---

## 2. Landing Page terdiri dari 3 halaman

Website memiliki tiga halaman utama:

- ✅ Login (`login.html`)

# 🚀 Cara Menjalankan Project

1. Clone repository

```bash
git clone https://github.com/username/videobelajar.git
```

2. Masuk ke folder project

```bash
cd videobelajar
```

3. Jalankan menggunakan browser

Buka salah satu file berikut:

```
login.html
```

atau

```
register.html
```

atau

```
beranda.html
```

Atau gunakan ekstensi **Live Server** pada Visual Studio Code.
